# E418 — Sensibilité radiale et première arrivée OFF (pré-enregistrée le 2026-11-03)

**Scénario synthétique (jamais présenté comme de vrais zéros).** À la hauteur réelle T = γ_r (rangs 1, 100, 2000), le membre
de ligne ½ + iT est remplacé par (1) une Tour seule β + iT et sa conjuguée (contrôle, brise la symétrie s ↔ 1−s) ;
(2) la paire miroir β + iT, 1−β + iT et leurs conjuguées (quartet complet, symétries de ζ respectées), β ∈ {0,3, 0,45, 0,49}.
Toutes les autres hauteurs sont conservées.

**Mesures.** déplacement des contacts (arctan(T/β) − arctan(2T))/T, rapport d'amplitude x^{β−½}, modules 1/|ρ| ; variation
des contributions et des accumulations (ΔΛ̂ᴮ, ΔΛ̂ᴬ sur W1) ; reclassements et erreurs de lecture des cassures (règle E416) ;
complément nécessaire pour conserver la lecture (= −Δ) ; **borne démontrable** du défaut : par accroissements finis sur la
seconde différence de x^{s+1}/(s(s+1)) (dérivée seconde x^{s−1}), |ΔΛ̂ᴮ(n)| ≤ 2[(n−1)^{−½} + Σ_{ρ nouveau} (n−1)^{Re ρ − 1}] ;
réponse collective : moindres carrés sur les amplitudes de 1000 zéros de ligne (hauteurs conservées) pour annuler Δ,
et constat que les coefficients obtenus ne sont pas des multiplicités entières.
