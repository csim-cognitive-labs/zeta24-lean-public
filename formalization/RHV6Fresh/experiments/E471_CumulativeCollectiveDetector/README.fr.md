# E471 (Ψ5) — détecteur collectif cumulé (appui, leçon d'E464/E466) — pré-enregistrement (2026-11-13)
Expérience chiffrée d'appui, aucun module Lean (la loi de résolution dans le sens direct est S9 d'E465 ; la réciproque est mesurée).
## Stratégie (règle R-Ψ)
* Cible : mesurer la signature cumulée d'une paire hors ligne dans la recomposition collective des 2 001 052 zéros.
* Objet cumulé : résidu de recomposition (coupure nette, sans Fejér, leçon E466) sur une grille géométrique 10^3 → 3·10^5 ; puis défaut cumulé exigé si le zéro de rang 1 000 est remplacé par une paire β ∈ {0,3 ; 0,4 ; 0,45} à sa hauteur.
* Pourquoi la lecture ponctuelle ne suffit pas : un point ne sépare pas une paire d'un zéro de ligne (E402 : jamais au-dessus des bornes démontrées).
* Signature attendue d'un hors-ligne : défaut cumulé croissant comme x^{1/2−β}·(constante) ; exposant ajusté sur la grille attendu à ±0,05 de 1/2 − β (attente écrite ; peut être réfutée).
* Suite dans les deux issues : appui pour Ψ1–Ψ4 ; ne démontre rien seul ; un exposant mesuré hors de ±0,05 est consigné comme tel.
