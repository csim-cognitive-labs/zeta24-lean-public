# Security and reports

> Français : [SECURITY.fr.md](SECURITY.fr.md)

- **Mathematical error or problem** (false statement, incomplete proof, non-reproducible numerical result, misleading vocabulary): open an issue on the repository, with the file reference and, if possible, the line.
- **No secret** (key, token, identifier) is stored in this repository, and none must be proposed for it. If you find one, report it through an issue without copying it.
- **No automatic workflow**: this repository contains no continuous-integration or automatic-execution configuration.
- The third-party code (`Zeta23Port`, `PNTPort`) is reported to its original authors as described in `THIRD_PARTY_NOTICES.md`; a copy of the report in this repository is welcome.
